# CSS Units :

- CSS units the size of elements such as text, width, height, margin, padding etc 

3 types :

1. px(fixed size)
2. em(Relative units)(It relates to it's parent element)
3. rem (Responsive)(Relative units)(Bydefault size 16px)


## Colors :

1. white
2. rgb(red,green,blue)
3. hex(#212121)
