# What is CSS Position

The position property determines the positioning method used for an element.

1. static(default)
2. relative(Positioned relative to its normal position)
3. absolute(Positioned relative to its ancestor)
4. fixed(Positioned relative to the viewport)
5. sticky(Behaves like relative, then sticks during scrolling)

Some common properties are:

1. top
2. right
3. bottom
4. left
5. inset
6. z-index

## Z-index : Higher the value will be placed on the top.
