# CSS Grid

CSS Grid Layout is a two-dimensional layout system that allows developers to divide a page into major regions or define the relationship between parts of a control using rows and columns. Unlike tables or flexbox, grid enables precise placement, overlapping, and layering of elements, making it ideal for complex, responsive web designs.

To create a grid, you set display: grid on a container and define its structure using properties like grid-template-columns and grid-template-rows. Items are then positioned within this grid using line numbers, named areas, or spanning techniques.

Key properties include:

1. display: grid: Activates the grid layout context.
2. grid-template-columns / grid-template-rows: Defines the size and number of tracks.
3. gap: Sets the spacing between rows and columns.
4. grid-column / grid-row: Positions specific items within the grid lines.
5. grid-template-areas: Allows naming and visually mapping grid regions for easier management.
